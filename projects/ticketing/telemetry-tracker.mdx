Telemetry Tracker is an MIT-licensed error tracker aimed at side projects and small teams on JavaScript and TypeScript stacks. It groups exceptions with release tags, symbolicates stacks when you upload source maps, and also records events, sessions and Web Vitals in the same store.

## Key Features

- **Error tracking**: Grouped issues, stack traces, release tags, and source map upload for readable frames.
- **Events and sessions**: Typed events with custom properties and session activity for anonymous or identified users.
- **Web Vitals**: LCP, INP, CLS and TTFB from real browser visits in the same SDK.
- **Alerts**: In-app, email, HTTPS webhooks, Slack, Discord, Microsoft Teams and Telegram.
- **SDKs**: Next.js, React, Vue/Nuxt (via `@telemetry-tracker/core`), React Native, Node.js and NestJS (via `@telemetry-tracker/node`).
- **Hosting**: Self-host with Docker/Postgres, or use the free hosted plan (250K ingest units/month, 14-day retention, 1 project).

## Self-hosting

See [DEPLOYMENT.md](https://github.com/Telemetry-Tracker/telemetry-tracker/blob/main/DEPLOYMENT.md) for Docker Compose and production guidance. The stack is a Fastify API, a Next.js dashboard and PostgreSQL.
