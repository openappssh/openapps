Posnic is open source POS and billing software for retail shops and restaurants.
It is designed around offline-first checkout: the primary application and
database can run on a shop computer, while operators can also deploy one
self-hosted server for several users in a single shop.

## Key Features

- **Sales and billing**: Keyboard- and touch-oriented checkout, barcode
  scanning, returns, held bills, quick sales, part payments, and tax invoices.
- **Inventory management**: Items, variants, categories, purchases, supplier
  returns, stock logs, and low-stock alerts.
- **Retail operations**: Customer accounts, staff roles, branch stock, and
  exportable sales, purchase, inventory, expense, and profit reports.
- **Restaurant workflows**: Kitchen order tickets, table management, kiosk
  support, and customer displays.
- **Hardware paths**: Documentation covers thermal printers, barcode scanners,
  cash drawers, weighing scales, and second displays. Exact devices still need
  testing against the project's hardware matrix.

## Deployment

Desktop release packages support local operation on Windows, macOS, and Linux.
The documented Ubuntu self-hosting path installs Node.js 22, MongoDB 8, Posnic,
and a systemd service. A self-hosted deployment uses one database for several
people; synchronization between separate tills or branches is a different
service and is not claimed as part of self-hosting.
